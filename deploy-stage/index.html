Everything you'd do at a 3270, without the 3270

Built to feel like the mainframe tooling developers already know from VS Code and Zowe Explorer — a persistent sidebar, tabs, syntax highlighting, and right-click actions, but reachable from any browser on the network.

📁

Data Sets

Browse, create, and rename PDS, sequential, VSAM, and zFS datasets, mount a zFS straight to a USS path, and edit members with syntax highlighting and column guides for JCL, COBOL, PL/I, and Assembler — the fixed-column rules enforced visually instead of silently breaking a compile.

📂

USS Files

A full Unix System Services file browser — navigate, edit, copy, move, rename, and delete files and directories, manage permissions, and jump straight to a recent path instead of clicking through the tree every time.

⚙

Jobs & Spool

Submit JCL straight from the editor, search and sort the job list, poll active jobs for live status updates, and drill into JESMSGLG, JESJCL, and every step's SYSPRINT as read-only tabs — no more hunting through SDSF.

📡

Live SYSLOG & TSO

A live, auto-refreshing SYSLOG tab for watching the system as it happens, plus issue operator (MODIFY/STOP) and TSO commands straight from the browser — no separate console session required.

★

Built for daily use

Favorites, a side-by-side compare view, resizable panels, and a workspace that remembers how you left it — the small conveniences that make a tool worth opening every day instead of tolerating.

Deploy once, on infrastructure you already run

The Gateway isn't a separate appliance or a hosted service — it's a set of files your own systems programmers deploy to z/OS.

1

Lives in USS

The whole app is static files in your z/OS system's Unix System Services filesystem

2

Served by IHS

Uses the IBM HTTP Server already available on z/OS — no new appliance or VM to provision

3

REST-API native

Talks directly to IBM's own z/OSMF REST APIs — no custom backend or database in between

4

RACF-secured

Every action is a real SAF-checked call under the signed-in user's own authority, not a shared service account

Deploy it on your own z/OS system

Secured behind RACF, talking straight to z/OSMF — see the README for the full deployment guide, from IHS setup to keyring configuration.
